## v1.1.6 : Hotfix Update for Skyrim 1.7.104 *(NOT A PUBLIC RELEASE)*

<br>

### **ZISS has been updated for compatibility with Skyrim 1.7.104.**

Unfortunately many mod authors have yet to update their mods for 1.7.104, with many authors stating they do not have plans to update them in the future. This means the only way to make ZISS compatible is to switch the modlist over to the Stock Game Method.

What this means is...

### **ZISS is now packaged with a complete copy of Skyrim v1.6.117.**

First, Wabbajack will check to see that you have Skyrim 1.7.104 installed. If you do, the installer will run as normal. Once installed, when you go to launch the game through MO2 it will launch using the v1.6.117 copy of the game.

<br>

### **There is nothing special you need to do here.<br>Just update Skyrim to v1.7.104 and then update ZISS to v1.1.6.**

The reason I am clarifying these details is because the file size of ZISS is now ~55gb post installation. It has always been my goal is try to keep this modlist as lightweight as possible. With that said, I have my hands tied here since Skyrim 1.6.117 must now be included in its entirety. I will be optimizing this further in the future so this file size should go down.

A version of ZISS utilizing only the Root Builder method will also be uploaded to the ZISS GitHub repo tonight. It will require you to downgrade Skyrim to v1.6.117, but if your running low on storage space, that may be the best option.
